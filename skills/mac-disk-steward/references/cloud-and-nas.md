# 云盘驻留与NAS迁移

## 云盘本地副本

先确认真实路径及提供商：Documents里的文件夹可能是iCloud File Provider投影；CloudStorage、Group Containers、CloudDocs与应用内部同步数据有不同职责，不能按名字判重或另造“主库”。检查上传完成、上传中、暂停、冲突与固定下载状态；目录状态与关键文件样本结合。用提供商/Finder原生“释放空间/移除下载”保留云端内容，不能 `rm` 云盘路径来释放本地副本。

前后核对路径、名称、逻辑大小、占位状态和本地分配量，按任务需要抽样核验云端；操作排队或返回成功不证明驻留已释放。provider未运行/报错时记录断点，避免反复reset触发重新物化；重启同步客户端或修改规则须符合当次授权，不能默认为清理必需。不要通过读遍占位文件、哈希所有云文件或复制到另一云目录来“验证”，这可能重新下载整批资料。

空目录使用拒绝非空对象的原生命令；同步删除、释放本地副本、同盘归档分开报告。本地回读不能证明云端传播完成。

## NAS归档

先判断保留价值。已经在Git吸收的临时补丁、旧下载包和无诊断价值产物不自动迁NAS；有历史成果/恢复价值的资料按模型、工作、应用类别存放，沿用合理旧位置。会话归档工具只承担其自身用途，普通开发文件不默认塞入会话库。

迁移前核对目标是已挂载的预期远程卷、容量足够且可读写。仅目录存在不足以证明NAS在线；可以核对 `os.path.ismount` 与 `statfs`/mount/fstyp或系统卷信息。挂载身份变化就停目标写入，保留源；不在本地同名目录继续写。不得在输出中暴露SMB URL中的账号凭据。

先复制或流式打包到临时名，复制成功后按清单核对文件内容、链接目标及所需权限、时间、ACL/扩展属性。普通树或tar的SHA-256辅助工具只覆盖内容和结构，元数据另行验证；有复杂元数据、Git、虚拟机或恢复价值时需在隔离目录实际恢复抽查。macOS元数据边车需要显式识别，不能为通过校验任意忽略未知额外成员。全部通过后才发布正式归档，并在删除源前确认源集合未变化。

小文件密集目录优先从本机流式打包到NAS，减少SMB逐文件传输开销，避免SSD又落一份完整大归档。容器挂NAS曾卡住，可改主机接收容器stdout并写NAS，及时关闭自己创建的临时容器。只在需要恢复时保存精简manifest、归档哈希和恢复入口；迁移产生的半成品与最终归档分开。

## 模型链接与本地例外

大型低频模型优先冷存，体积较小、频繁调用且影响工作延迟的模型按用户选择留本地。迁移前看下载暂存、模型及运行输出的完整空间预算，不能仅挪最终权重而留多份重复下载。

先小样本测试SMB链接语义：HuggingFace快照相对链接在部分SMB实现上会成为XSym普通占位文件，`copy`成功不等于权重可读。按真实目标检查快照到blob的路径，保留可用链接或显式物化必要实体，校验哈希并计量额外复制。保留旧调用入口时，回读本地软链接及最终NAS文件；safetensors头/长度与JSON结构校验、全文件哈希、实际推理是不同证据层。未跑推理就明确记录。

NAS不在线时说明调用依赖，不静默回退下载到SSD。原路径和调用配置的兼容调整应交给实际配置owner；历史username、模型名、NAS地址留在本机profile，通用Skill不固定它们。

## SMB繁忙与失败传输片段

先确认片段是本次已知半成品、正式文件存在且符合原记录，检查本机打开句柄及仍在运行的传输。`lsof`无句柄只排除本机进程，不能排除NAS服务端/其他客户端锁。保留精确片段路径和错误，允许其他独立工作继续；之后先回读再对同一片段重试，删除成功核对正式文件与残留列表。

单个文件繁忙不默认触发强制卸载整个共享、关闭其他任务或重启NAS。确需影响其他使用者的连接/服务操作时，先完成精确诊断并具体说明影响；现有授权不足才询问。不得使用“按partial后缀全部删除”代替确认对象。
