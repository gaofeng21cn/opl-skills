# Mac 磁盘诊断与整理

先解释空间去了哪里，再判断哪些内容应当保留及放在哪里；反复增长的目录追到生成它的工具或任务。用当次证据行动，历史目录、缓存年龄、旧用途和本机配置均不构成删除规则。

## 范围与入口

按当前请求确定设备、卷、目标和授权。只读查询、复盘、评估保持只读；“清理、整理、优化”包含必要的定点处理和验证，沿用本会话已有授权。只在缺失决定实质影响对象、用途或不可逆处置时询问；先完成其他独立工作。Skill 不要求每批重新确认，也不授权定时任务、跨机器修改、停止活跃服务或更改备份策略。

如存在 `~/.config/mac-disk-steward/profile.json`，只读其中的 NAS 目标、本地保留项、既有偏好和证据入口；执行前验证挂载及当前用途。无配置照常诊断，不自动生成另一套目录或归档库。通用方法与机器路径分开维护。

## 判断与执行

1. **建立同口径基线。** 记录设备/卷身份、时间、实际可用字节、主要本地目录、快照和备份状态。先与上次比较，向新增量大的区域深入；无基线时用创建/修改时间、下载或制作记录追到具体事件，注明推断边界。浅层扫描共享一次结果，避免并发重复遍历整盘、读取私人正文或触发云盘下载。不能读取的目录计为未知，必要时用服务官方接口补齐。
2. **按用途选择动作。** 可重建且无当前依赖的缓存/无价值过程文件删除；有价值但低频的大资产迁往NAS；已上传且无需离线的云盘文件用提供商原生功能释放本地副本；当前工作、持久数据和高频必要资产保留。体积、年龄、文件名前缀、Git忽略、停止状态、未挂接或无打开句柄都不能单独证明可删。查看真实配置/脚本引用、未吸收改动、唯一成果和恢复条件；证据足够即停止扩展调查。
3. **处理精确集合。** 记录实际路径或服务对象ID、用途、动作、理由及必要恢复入口。优先应用/包管理器原生命令；空目录用 `rmdir`。迁移先复制/打包、验证后再移除源，源变化则跳过该对象。需要回收资料时检查内容和必要元数据；可重建缓存无需全部哈希或另存永久备份。历史授权只在当前对象和用途仍匹配时适用。
4. **回读真实结果。** 核对目标不存在/已迁移、保留集合和受影响调用方可用；把对象删除、服务内部回收、宿主磁盘实际增加空间分别报告。退出码与结果未知时先回读，避免重复修改。后台写入影响净值就标出时间和并发因素，不能将目录减量强行解释为物理回收量。
5. **留下下次能用的基线。** 保存精简的处理/保留集合、实际可用量、恢复位置和未解决的生成入口。重复来源优先在已有测试/构建/下载/审看工具中落实清理生命周期和保留预算；是否修改源码、推送或配置仍按当前任务授权。一次删除不宣称长期根治，不默认添加定时清理。

## 两条计量约束

文件逻辑大小、目录分配量、APFS容器/同一卷的实际可用量分别记录。父子目录、硬链接/APFS克隆、Docker对象与虚拟盘、各轮快照收益可能重叠；不累计成虚假的总回收量。NAS删除量不计入SSD收益，同盘归档或移入废纸篓也不代表容量已释放。

数据必要性由AI结合用途和证据判断；脚本只测量身份、字节、链接、哈希和状态等确定性边界。机器可验证完整性，不批准“无用”或允许删除。

## 可复用工具

脚本仅使用 Python 标准库，不删除源文件、不维护数据库、不回收快照。输出文件采用独占创建，避免覆盖旧基线；把证据写到本次任务 `work/`，精简交付写到用户要求的位置。

- `python3 scripts/disk_baseline.py capture --root <已确认本地目录> --output <基线.json>`：记录本机Data卷身份、空间、选定目录分配量及Time Machine状态。`--root` 可重复；不传则只取空间和状态。按需设置 `--volume` 和 `--timeout`，不要每次展开整个用户目录。
- `python3 scripts/disk_baseline.py compare <旧.json> <新.json> --output <增量.json>`：拒绝不同设备/卷的比较；空间净变化和各独立目录增量分开，不求和。
- `python3 scripts/verify_copy.py manifest <源目录> --output <清单.json>`，再用 `tree <清单.json> <副本目录>` 或 `tar <清单.json> <归档.tar.gz>`：逐文件SHA-256及树结构校验。只对已确认可读取/归档的普通目录运行；默认拒绝云盘占位、跨卷子树和特殊文件。NAS上链接的语义及恢复测试另按指南核对，内容清单不证明ACL/扩展属性已保存。详细参数见 `--help`；tar只流式读取，不提取归档。验证失败保留源并修复具体断点。

最终简洁说明实际空闲量、主要来源、已处理/保留对象、恢复入口和真实阻塞；当前记录与历史检查点分开，保留原证据，不把旧快照中的数字改成新数字。
